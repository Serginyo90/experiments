# experiments

## About

A personal sandbox of small, focused projects covering different areas of web
and backend development: JWT auth, Server-Sent Events, long polling, Node.js
streams, an event emitter, XSS / Content Security Policy, a Netflix-style
thumbnail preview, and plain HTML/CSS practice pages. It also holds a
collection of exported [n8n](https://n8n.io/) workflow templates (chatbot with
RAG + Pinecone, a customer support agent, an expense logger, and an email
cleanup workflow).

Most of these projects were built as companion code for the
[YouTube channel @serginyo90](https://www.youtube.com/@serginyo90)
(Russian-language tutorials). Each subfolder is self-contained, with its own
`package.json` and, where relevant, its own README with setup instructions.
